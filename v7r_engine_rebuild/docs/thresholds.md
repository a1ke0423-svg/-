# 閾値の基準（STEP5・STEP6）

- 決定日: 2026-10-30
- 方針: 経験則で仮の値を決め、過去データで妥当かを確認する（選択肢 3）
- 固定ルール: 30 レースの蓄積を始める前に、値を確定する。蓄積後は、結果を見て値を変えない
- 値を変えてよいのは、30 レース開始前の確認段階だけ

## 区分

- **設計文書**: 設計文書 0.1.0 に数字が書かれているもの。変更不可（承認が必要）
- **仮（提案）**: 設計文書に数字が無く、私が提案したもの。30 レース開始前に、見直せる

## 値

| 項目 | 値 | 区分 | 基準・理由 |
|---|---|---|---|
| 展開被害の崩壊判定 | ≥ 0.60 | 設計文書 | 展開被害がこの値以上なら、展開で崩れる可能性ありとみなす |
| 位置取り失敗（先行寄り） | 通過位置指数 < 0.35 かつ想定ハイ | 設計文書 | 前に行く馬が、ハイペースで位置を取れない |
| 位置取り失敗（後方寄り） | 通過位置指数 > 0.65 かつ想定スロー | 設計文書 | 後ろの馬が、スローで届かない |
| 位置取り失敗（WPR） | WPR < 0.50 | 設計文書 | 能力を出せる位置に入る割合が低い |
| 適性不足 | 距離・コース・馬場の適性 < 0.50 | 設計文書 | 同条件での好走率が低い |
| 騎手実行リスク | 騎手指標 < 0.50 かつ不一致あり | 設計文書 | 騎手単独では採用しない |
| 相手（能力が近い） | 能力差 ≤ 0.10 かつ理想位置が重なる | 設計文書 | 同じ位置で争う、能力が近い相手 |
| 能力高・WPR低の矛盾 | 能力 ≥ 0.80 かつ WPR < 0.50 | 設計文書 | 能力と位置取りが噛み合わない |
| 理想ペース（前寄り） | 通過位置指数 < 0.35 → スロー | 仮（提案） | 前寄りの馬は、スローで力を出しやすい |
| 理想ペース（後寄り） | 通過位置指数 > 0.65 → ハイ | 仮（提案） | 後寄りの馬は、ハイで力を出しやすい |
| 勝利条件（能力） | 能力スコア ≥ 0.80 | 仮（提案） | 直近の着順が安定して上位にある |
| 敗北条件（能力） | 能力スコア < 0.50 | 仮（提案） | 直近の着順が安定して下位にある |

## 注意

- 「仮（提案）」の値は、私が決めた数字です。根拠は経験則に近く、データでの裏付けはありません。
- 過去データで確認して、妥当でなければ、30 レース開始前に値を直せます。
- 直す場合は、この文書に理由を書いてから変えます。
